# amazon-prime-eda-project
EDA Analysis of Amazon Prime Movies &amp; TV Shows Dataset

## 📌 Project Overview
This project analyzes Amazon Prime Movies and TV Shows dataset to identify trends, patterns, and insights using Python.

## 📊 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📁 Datasets
- credits.csv
- titles.csv

## 📈 Visualizations
- Movies vs TV Shows distribution
- Titles per year
- Top genres
- IMDb vs TMDb scores
- Rating distribution
- Actor & Director analysis
- Correlation heatmap
- Content duration analysis

## 🔍 Key Insights
- Movies dominate over TV Shows
- Drama and Action are most common genres
- Ratings show moderate correlation
- Content increased significantly after 2015

## 📌 Conclusion
This analysis helps understand content strategy, audience preference, and growth trends of Amazon Prime.
